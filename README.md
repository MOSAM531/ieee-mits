# IEEE MTT-S Student Branch Chapter — MITS-DU Gwalior 📡

A clean, responsive, single-page website for the **IEEE Microwave Theory and Technology Society (MTT-S) Student Branch Chapter** at **Madhav Institute of Technology & Science (Deemed to be University), Gwalior (M.P.)**.

---

## 📌 Features Included

1. **IEEE MTT-S Introduction:** Overview of the global society and its mission in RF, microwave, and wireless technologies.
2. **About the Chapter:** Background of the student branch chapter at MITS-DU Gwalior.
3. **Upcoming Event/Workshop Section:** Highlight of *"Electrowave '26: Hands-on Antenna Design & RF Simulation"* with date, time, venue, and fee.
4. **Domains & Activities:** 4 distinct student teams (Technical & RF Design, Web & Tech Ops, Design & Media, Events & PR).
5. **Contact & Quick Registration:** Complete contact details for MITS ECE Department, student coordinators, and an interactive registration form.
6. **Working Buttons & Links:**
   - Smooth navigation menu links (`#home`, `#about`, `#events`, `#domains`, `#contact`)
   - "Register For This Workshop" working action button
   - Interactive registration form with real-time phone validation and visual confirmation notification.
   - Mobile responsive navigation bar with hamburger menu.

## 🚀 How to Host & Get Live Website Link (GitHub Pages in 2 Minutes)

Since you don't need any complex command-line tools, follow these simple beginner steps:

### Option A: Via GitHub (Free Live URL)
1. Go to [github.com](https://github.com) and log in.
2. Click **New** to create a new repository (name it `ieee-mtts-mits`).
3. Select **Public** and click **Create repository**.
4. On the next screen, click the link: **"uploading an existing file"**.
5. Drag and drop all files from this folder (`index.html`, `style.css`, `script.js`, `README.md`) into GitHub.
6. Click **Commit changes**.
7. Go to **Settings** $\rightarrow$ **Pages** (on the left menu).
8. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
9. Wait 30 seconds and refresh — your free live link will be ready:  
   👉 `https://<your-username>.github.io/ieee-mtts-mits/`

---

### Option B: Free Drag-and-Drop Deploy on Netlify (Instant 10-second link)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop the `ieee-mtts-mits` folder directly into the browser.
3. Instantly get a live `.netlify.app` public link!
